写一份题解代码要用最简洁且正确的，格式与内容必须严格按照以下要求：

## 题目结构

1. 解题思路
   * 逻辑清晰，简洁明了
   * 必须提及相关算法
   * 给出核心思路与实现方法
   * 要分几点来说明，不能直接一大段话放上去
2. 复杂度分析
   * 分析时间复杂度和空间复杂度
   * 必须保证复杂度合适
3. 代码实现
   * 提供 **Python、Java、C++、JavaScript、C** 五种语言代码
   * 要有输入操作,输入输出写在主函数里，题面要实现的功能写在外部函数里
   * 代码为 **ACM 风格**，类名统一为 Main（Java）
   * Java 根据数据范围调整输入方式，默认不用快读。
   * 每段代码都要有中文注释，关键步骤必须加注释
   * 不要使用太高级的语法，保持简洁易懂
   * 默认输入数据合法

## 格式要求

* 一级标题为题目名称
* 二级标题为大标题（解题思路、复杂度分析、代码实现）
* 三级标题为小标题（Python、Java、C++、JavaScript、C）
* 题解正文（解题思路、复杂度分析等，代码围栏外）里的变量、字母、数字、复杂度与公式必须用 `$` 框起来（行内 `$...$`，多行 `$$...$$`），例如 $n$、$O(n)$、$0 \le p \le n$
* 禁止用反引号 `` ` `` 框变量或公式，也禁止写成 `` `$n$` `` 这种套娃
* 代码块内部保持源码原样，不必改成 `$`
* 不要加粗标题
* 五语言必须连续写在「代码实现」下（`### Python` … `### C` + 围栏），中间不要插正文；围栏语言标记用 `python` / `java` / `cpp` / `javascript` / `c`。渔启 IDE 会收成一张语言页签卡片，一次只显示一种语言。
