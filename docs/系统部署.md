# FishOJ 新机安装（逐步复制命令）

在一台**空的** Ubuntu 22.04 / Debian 12（x86_64）上，按顺序复制本文命令即可装出完整 FishOJ（Hydro 核心 + 本仓库插件）。  
**不要** `git clone hydro-dev/Hydro` 自己编译。  
从旧机搬用户和题库：新机装完并能打开网站后，做本文第 11 节。

开始前在云控制台确认（不是 SSH 命令）：

- 镜像：**Ubuntu 22.04**（或 Debian 12），不要 Alibaba Cloud Linux / CentOS / 宝塔。
- 规格：建议 **≥ 4C8G**。
- 安全组入方向只放行 **22、80**（有备案域名再加 443）。不要放行 27017 / 8888 / 5050。
- 所有安装命令必须在 **root** 下执行。
- 每次只复制**一个**代码块。跑完、出现 `root@...#` 后再复制下一块，不要把相邻两段粘在一起。

把下面的 `你的公网IP` 换成实际 IP。仓库地址默认：

`https://github.com/yujun2007plus/FishOJ.git`

---

## 1. 登录并切到 root

```bash
sudo su
whoami
cat /etc/os-release
uname -m
```

`whoami` 必须是 `root`，系统必须是 Ubuntu 22.04 或 Debian 12，`uname -m` 必须是 `x86_64`。

---

## 2. 安装官方 Hydro

会装 Nix、Node、MongoDB、评测沙箱、Caddy、PM2。可能要几十分钟，中间若出现 QQ 二维码可忽略。

```bash
LANG=zh . <(curl https://hydro.ac/setup.sh)
```

清华 Nix 镜像失败时改用这一条（仍是同一脚本）：

```bash
nix_install_source=https://mirrors.ustc.edu.cn/nix/latest/install LANG=zh . <(curl https://hydro.ac/setup.sh)
```

脚本若 `exit` 把你踢回 `admin@`，再执行：

```bash
sudo su
. /root/.nix-profile/etc/profile.d/nix.sh
which nix
LANG=zh . <(curl https://hydro.ac/setup.sh)
```

不要同时开两个安装。看到安装完成后再往下。

---

## 3. 确认核心进程

新开一次 root 会话，或先加载环境：

```bash
. /root/.nix-profile/etc/profile.d/nix.sh
bash -lc 'pm2 list'
```

应看到 `hydrooj`、`mongodb`、`hydro-sandbox`、`caddy`，状态 **online**。  
浏览器打开 `http://你的公网IP/` ，能出 Hydro 注册页即可。打不开先查安全组是否放行 80。

`pm2: command not found` 表示第 2 步没装完，回到第 2 步重跑脚本，不要先拷插件。

---

## 4. 注册第一个管理员

1. 浏览器打开 `http://你的公网IP/` ，注册第一个账号。
2. 服务器执行（uid 一般是 `2`，以控制面板用户列表为准）：

```bash
bash -lc 'hydrooj cli user setSuperAdmin 2'
```

刷新页面应出现「控制面板」。在系统设置里把 **Server BaseURL** 填成（末尾必须有 `/`）：

```
http://你的公网IP/
```

有域名后再改成 `https://你的域名/`。

---

## 5. 把本仓库插件放到服务器

任选一种。目标目录必须是 `/root/.hydro/addons/`。

### 方式 A：在服务器 git clone（推荐）

若仓库是私有的，先配好本机 deploy key 或改用 HTTPS + token。  
**每次只复制一个代码块**，等终端重新出现 `root@...#` 再复制下一块，不要把两段粘在一起。

**A1. 安装 git**（你这边若已经跑完，跳过，直接做 A2）

```bash
apt-get update
apt-get install -y git
```

**A2. 克隆仓库并拷到插件目录**

```bash
mkdir -p /root/.hydro/addons
cd /root
git clone https://github.com/yujun2007plus/FishOJ.git /root/FishOJ
cp -a /root/FishOJ/addons/. /root/.hydro/addons/
ls /root/.hydro/addons
```

`ls` 里应有：`ProblemIde` `LearningScaffold` `AiTutor` `AiAssistant` `AiAnalysis` `OfficialSolution` `HomePage` `VipIntroPage` `FishOjTheme` `hydroac-client`。

以后更新插件：

```bash
cd /root/FishOJ
git pull
cp -a /root/FishOJ/addons/. /root/.hydro/addons/
bash -lc 'pm2 restart hydrooj'
```

### 方式 B：从 Windows 本机 scp

在 **本机** PowerShell（仓库根目录 `D:\FishOJ`）执行，把 IP 换成新机：

```powershell
ssh root@你的公网IP "mkdir -p /root/.hydro/addons"
scp -r addons/ProblemIde,addons/LearningScaffold,addons/AiTutor,addons/AiAssistant,addons/AiAnalysis,addons/OfficialSolution,addons/HomePage,addons/VipIntroPage,addons/FishOjTheme,addons/hydroac-client root@你的公网IP:/root/.hydro/addons/
```

OpenSSH 的 `scp -r` 不支持逗号列表时，改成逐个目录：

```powershell
scp -r addons/ProblemIde addons/LearningScaffold addons/AiTutor addons/AiAssistant addons/AiAnalysis addons/OfficialSolution addons/HomePage addons/VipIntroPage addons/FishOjTheme addons/hydroac-client root@你的公网IP:/root/.hydro/addons/
```

同时把 Caddy 样例拷上去（第 7 步要用）：

```powershell
scp server-config/Caddyfile root@你的公网IP:/root/.hydro/Caddyfile
```

## 6. 注册插件并重启

在**服务器 root** 执行：

```bash
. /root/.nix-profile/etc/profile.d/nix.sh
hydrooj addon add /root/.hydro/addons/hydroac-client
hydrooj addon add /root/.hydro/addons/ProblemIde
hydrooj addon add /root/.hydro/addons/LearningScaffold
hydrooj addon add /root/.hydro/addons/AiTutor
hydrooj addon add /root/.hydro/addons/AiAssistant
hydrooj addon add /root/.hydro/addons/AiAnalysis
hydrooj addon add /root/.hydro/addons/OfficialSolution
hydrooj addon add /root/.hydro/addons/HomePage
hydrooj addon add /root/.hydro/addons/VipIntroPage
hydrooj addon add /root/.hydro/addons/FishOjTheme
pm2 restart hydrooj
pm2 list
cat /root/.hydro/addon.json
```

`addon.json` 里应出现上述绝对路径。浏览器硬刷新后再试 `/ide/<题号>`（先要在控制面板建一道编程题）。

---

## 7. Caddy（AI 流式 30 分钟超时）

若第 5 步用了（若使用了方案A） git clone：

```bash
cp /root/FishOJ/server-config/Caddyfile /root/.hydro/Caddyfile
cd /root/.hydro
bash -lc 'caddy reload'
pm2 restart caddy
```
若第 5 步选择方式 B
若已经用 scp 覆盖过 `/root/.hydro/Caddyfile`，只执行：

```bash
cd /root/.hydro
bash -lc 'caddy reload'
pm2 restart caddy
```

有备案域名后，把 Caddyfile 里的 `:80` 改成域名，再 `caddy reload`，安全组放行 443。

## 8. 写入 AI 密钥

把下面的 `sk-替换成你的key` 改成真 Key。**不要**把填好的文件提交进 Git。

```bash
cat > /root/.hydro/fishoj.env <<'EOF'
DEEPSEEK_API_KEY=sk-替换成你的key
BUILTIN_API_KEY=sk-替换成你的key
FISHOJ_AI_API_KEY=sk-替换成你的key
EOF
chmod 600 /root/.hydro/fishoj.env
```

注入登录环境和 PM2：

```bash
grep -q fishoj.env /root/.bashrc || echo '[ -f /root/.hydro/fishoj.env ] && set -a && . /root/.hydro/fishoj.env && set +a' >> /root/.bashrc
grep -q fishoj.env /root/.profile || echo '[ -f /root/.hydro/fishoj.env ] && set -a && . /root/.hydro/fishoj.env && set +a' >> /root/.profile
set -a
. /root/.hydro/fishoj.env
set +a
while IFS= read -r line; do
  [[ "$line" =~ ^[A-Za-z_][A-Za-z0-9_]*= ]] || continue
  key="${line%%=*}"
  grep -v "^${key}=" /etc/environment > /etc/environment.fishoj.tmp 2>/dev/null || true
  mv /etc/environment.fishoj.tmp /etc/environment 2>/dev/null || true
  echo "$line" >> /etc/environment
done < /root/.hydro/fishoj.env
pm2 restart hydrooj --update-env
```

只确认变量名存在，不要把值贴到聊天：

```bash
tr '\0' '\n' < /proc/$(bash -lc 'pm2 pid hydrooj')/environ | grep -E 'KEY|TOKEN' | cut -d= -f1
```

应能看到 `DEEPSEEK_API_KEY`、`BUILTIN_API_KEY`、`FISHOJ_AI_API_KEY`。若仍报 `/proc//environ`，等几秒再跑；`pm2 pid hydrooj` 必须是一个数字。

小助手也可用控制面板里的 Key（会进 Mongo）；环境变量优先。

## 9. 验收

```bash
bash -lc 'pm2 list'
bash -lc 'pm2 logs hydrooj --lines 30'
```

浏览器（硬刷新）检查：

1. `http://你的公网IP/` 能开，超管能进控制面板。
2. 建一道编程题，打开 `/ide/<pid>`：题面、编辑器、自测、提交、评测有结果。
3. AI 助教一轮对话、AI 分析一次（确认 Key 生效）。
4. 四进程保持 online，日志无循环报错。

## 10. 以后常用命令

都在 root 下，先加载环境：

```bash
. /root/.nix-profile/etc/profile.d/nix.sh
pm2 list
pm2 restart hydrooj
pm2 logs hydrooj --lines 50
hydrooj cli user setSuperAdmin <uid>
hydrooj addon add /root/.hydro/addons/<插件目录名>
```

官方备份（当前目录生成 zip）：

```bash
bash -lc 'cd /root && hydrooj backup'
```

## 常见失败（对应命令）

**网站打不开**

```bash
ss -lntp | grep -E ':80|:8888'
bash -lc 'pm2 list'
```

先确认安全组放行 80，再确认 `caddy` / `hydrooj` online。

**`hydrooj` / `pm2` 找不到**

```bash
sudo su
. /root/.nix-profile/etc/profile.d/nix.sh
which nix
bash -lc 'pm2 list'
```

仍没有：回到第 2 步重跑 `setup.sh`。

**能打开但不能评测**

```bash
bash -lc 'pm2 list'
bash -lc 'pm2 logs hydro-sandbox --lines 50'
```

`hydro-sandbox` 必须 online；ARM 机器容易缺编译器，请用 x86_64。

**插件页 404**

```bash
ls /root/.hydro/addons
cat /root/.hydro/addon.json
bash -lc 'hydrooj addon add /root/.hydro/addons/ProblemIde'
bash -lc 'pm2 restart hydrooj'
```

必须用**绝对路径** `addon add`。

**AI 全挂、做题正常**

密钥没进 hydrooj 进程：重做第 8 步，并执行 `pm2 restart hydrooj --update-env`。

**安装卡在 gzip / base64 invalid**

下载被截断，同一条脚本再跑一次即可（Nix 已装会跳过）。

**内存不够编沙箱**

```bash
fallocate -l 4G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
LANG=zh . <(curl https://hydro.ac/setup.sh)
```

## 11. 导入旧机数据（覆盖新机当前库）

新机已经能打开网站后再做。导入会 **覆盖** 新机 Mongo（含刚注册的 `yujun`）、`/root/.hydro` 里的配置和题目文件。导入后用**旧机超管**登录。旧机先别关。

默认：旧机 `8.163.87.247`，新机 `8.138.202.167`。以控制台实际 IP 为准。  
每次只复制**一个**代码块。

### 11.1 把导出脚本拷到旧机

在 **Windows** 本机，仓库根目录 `D:\FishOJ` 的 PowerShell：

```powershell
scp server-config/migrate/01-export-old.sh root@8.163.87.247:/root/
```

### 11.2 旧机导出

SSH 登录**旧机**，切 root：

```bash
sudo su
. /root/.nix-profile/etc/profile.d/nix.sh
sed -i 's/\r$//' /root/01-export-old.sh
bash -lc 'bash /root/01-export-old.sh'
ls -lh /root/fishoj-migrate/fishoj-full-migrate-*.tar.gz
```

应出现一个 `fishoj-full-migrate-*.tar.gz`（可能数 GB）。包里有密钥，**不要 git add**。

### 11.3 把全量包拷到新机

仍在 **Windows** PowerShell（先建本地暂存，再上传新机）：

```powershell
mkdir D:\FishOJ-migrate-backup
scp root@8.163.87.247:/root/fishoj-migrate/fishoj-full-migrate-*.tar.gz D:\FishOJ-migrate-backup\
scp D:\FishOJ-migrate-backup\fishoj-full-migrate-*.tar.gz root@8.138.202.167:/root/fishoj-migrate/
```

若没有 `fishoj-migrate` 目录，先 SSH 新机执行：

```bash
mkdir -p /root/fishoj-migrate
```

再重新跑上面的第二条 `scp`。两台都是 Linux 时也可以旧机直接：

```bash
scp /root/fishoj-migrate/fishoj-full-migrate-*.tar.gz root@8.138.202.167:/root/fishoj-migrate/
```

### 11.4 新机导入

在**新机** root：

```bash
. /root/.nix-profile/etc/profile.d/nix.sh
cp /root/FishOJ/server-config/migrate/02-import-new.sh /root/
sed -i 's/\r$//' /root/02-import-new.sh
ls /root/fishoj-migrate
bash -lc 'bash /root/02-import-new.sh /root/fishoj-migrate'
```

脚本会停 `hydrooj` → 恢复 Mongo → 解开旧 `.hydro` → 按清单注册插件 → 把旧密钥写入 PM2 → 重启。

### 11.5 用本仓库最新插件盖回去

导入的是旧机插件，可能比现在仓库旧。新机执行：

```bash
cp -a /root/FishOJ/addons/. /root/.hydro/addons/
cp /root/FishOJ/server-config/Caddyfile /root/.hydro/Caddyfile
. /root/.nix-profile/etc/profile.d/nix.sh
hydrooj addon add /root/.hydro/addons/hydroac-client
hydrooj addon add /root/.hydro/addons/ProblemIde
hydrooj addon add /root/.hydro/addons/LearningScaffold
hydrooj addon add /root/.hydro/addons/AiTutor
hydrooj addon add /root/.hydro/addons/AiAssistant
hydrooj addon add /root/.hydro/addons/AiAnalysis
hydrooj addon add /root/.hydro/addons/OfficialSolution
hydrooj addon add /root/.hydro/addons/HomePage
hydrooj addon add /root/.hydro/addons/VipIntroPage
hydrooj addon add /root/.hydro/addons/FishOjTheme
cd /root/.hydro
bash -lc 'caddy reload'
pm2 restart hydrooj --update-env
pm2 restart caddy
```

控制面板里把 **Server BaseURL** 改成新机：

```
http://8.138.202.167/
```

用**旧机账号**登录，测：首页、旧题 `/ide/<pid>`、提交评测、AI 助教。通过后再改 DNS/访问入口；旧机建议再留 48 小时。

## 12. 导入一本通题包 `题库/ybtbas.zip`

这是 Hydro 官方格式的「一本通编程启蒙」包（包内 `README.txt`），评测走 `hydroac-client` 远程判题。新机日志里已有 `hydroac-remotejudge connection established` 即可导入。每次只复制一个代码块。

### 12.1 Windows 把 zip 拷到新机

在本机 PowerShell（仓库在 `D:\FishOJ`）：

```powershell
scp "D:\FishOJ\题库\ybtbas.zip" root@8.138.202.167:/root/ybtbas.zip
```

### 12.2 新机 CLI 导入到默认域 `system`

```bash
. /root/.nix-profile/etc/profile.d/nix.sh
ls -lh /root/ybtbas.zip
hydrooj cli problem import system /root/ybtbas.zip
pm2 restart hydrooj
```

导入可能要几分钟。完成后浏览器硬刷新打开 [题库](http://8.138.202.167/p)，应能看到 `P1` 等「一本通」标签题。做题入口：`/ide/P1`。

网页备选：超管登录 → 题库右侧 **从 Hydro 导入** → 上传 `ybtbas.zip`（与包内说明一致）。zip 只有约 0.5MB，网页一般也能传。

不要把该 zip `git add` 进公开仓库。

## 装完东西在哪

| 内容 | 路径 |
|------|------|
| Hydro 配置、插件、Caddyfile | `/root/.hydro/` |
| 本仓库（若用 git clone） | `/root/FishOJ/` |
| Mongo 数据文件 | `/data/db`（不要直接拷目录） |
| 题目文件 / 测例 | `/data/file` |
| AI 密钥 | `/root/.hydro/fishoj.env`（权限 600） |

更新 Hydro 不要改 Nix 里的官方包，只更新 `/root/.hydro/addons/`。旧数据导入见上文第 11 节。
